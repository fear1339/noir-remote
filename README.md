# NOIR Remote update channel

Файлы для публичного репозитория `fear1339/noir-remote`:

- `update.json` — описание последней версии;
- `NOIR-Remote-1.0.0.apk` — подписанный APK.

Каждое обновление должно иметь больший `versionCode`, быть подписано ключом
`NOIR-TV/.toolchain/noir-remote-release.jks` и содержать актуальный SHA-256.
